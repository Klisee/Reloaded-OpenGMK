# Reloaded OpenGMK 1.0.0

## Launcher

- Primera versión de Reloaded OpenGMK.
- Renombrado de Pokémon Reloaded a Reloaded OpenGMK.
- Es la primera vez que se convierte en un launcher.
- Soporte multiplataforma y primera versión en Kotlin Multiplatform (KMP); antes era Kotlin con soporte únicamente para Android.
- Primer lanzamiento para Android, Linux y Windows, con futuro soporte para iOS y macOS.
- Interfaz totalmente renovada, con un diseño Liquid Glass como extra.
- Interfaz base al estilo Material Expressive.
- Independencia en el feed principal del blog de F3R.

## Motor

- Soporte oficial para Vulkan, DirectX y Metal nativo.
- Prototipo reimplementado del Online de Zibelan, totalmente de código abierto.
- Ahora se usa wgpu para dar soporte a tecnologías más modernas.
